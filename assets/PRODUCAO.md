# Produção das capas

As capas PNG foram produzidas com a ferramenta integrada de geração de imagens, usando provas compostas com o arquivo real da Archivo no peso 400. Os demais componentes usam os contornos extraídos desse arquivo tipográfico.

## Capa clara

Use case: ads-marketing. Asset type: final light theme PNG cover for a GitHub profile. The supplied image is an authoritative typeset reference using the real Archivo Regular font at weight 400. Reproduce its typography and flat layout faithfully in a finished high-resolution horizontal PNG. Use ONLY Archivo REGULAR, weight 400, for EVERY line, INCLUDING the large name; no semibold or bold anywhere, no variable font weight changes. Contrast comes exclusively from point sizes. Keep the exact letter shapes, normal regular stroke thickness, proportions, hierarchy and left alignment shown in the reference. Exact text: top-left '[DESIGN // WEB // IA]'; huge main name 'Rafael Poles®', with only R and P capitalized and one small raised registered sign; subtitle 'Marcas, sites e interfaces.'; small bottom-left 'São Paulo, Brasil'. Keep the single fine horizontal divider at the bottom. Background solid #FFFFFF, ALL foreground lettering and linework #000000. Strictly monochrome, no sage green or grey accent. Use the same wide 1944 by 809 proportions as the reference, substantial whitespace and large legible name. No orbit graphic, no symbol other than the registered sign, no decorative icon, no border or mockup, no shadows, no gradients, no texture. Preserve the true REGULAR typography of the supplied specimen; do not thicken or embolden the title or subtitle.
