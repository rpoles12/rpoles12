# Identidade do perfil

Tipografia dos componentes: Archivo Regular, peso 400, largura normal.
Não há negrito, semibold ou contraste por peso. A hierarquia usa tamanhos.

Como o GitHub remove CSS personalizado do README, títulos, textos, labels,
cards e botões usam SVGs com a tipografia convertida em contornos.
Assim, não dependem de fontes instaladas no computador de quem visita.
Os parágrafos têm versões de composição para desktop e celular.
Os textos equivalentes constam nos atributos alt das imagens do README.

As capas PNG foram geradas com a ferramenta integrada de imagens, a partir
de provas tipográficas renderizadas com o arquivo real da Archivo Regular.
O nome usa apenas iniciais maiúsculas e um único registro em sobrescrito.

Paleta dos componentes: preto #000000 e branco #FFFFFF; fundo transparente.
A capa escura usa #0D1117 para integrar com o tema escuro padrão do GitHub.
Os ícones e botões usam somente traçados, sem preenchimento de fundo.
Os botões usam raio equivalente à metade da altura: formato de pílula.

Os links e as quatro experiências de projeto foram preservados.
